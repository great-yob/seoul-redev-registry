# 7. 상도16구역 (신통기획)

- **위치** 동작구 상도동 214번지 일대. 국사봉 일대 고지대, 동작구 대표 낙후지역 (B)
- **사업방식** 신속통합기획 민간재개발(도시정비법)
- **단계** 2023 추진준비위 발족 → 2025-08-27 서울시 제4차 주택재개발사업 후보지 선정위원회에서 신통기획 후보지 선정(신청 동의율 약 63%) → 2026-01 추진위 구성 동의서 징구 착수 → 2026-02-05 기준 동의율 약 45%(요건 50% 미달) → 2026년 연내 정비구역 지정 고시 목표
  - 2026-08월 매체 기준 여전히 '사업 초기 단계'로 분류
- **동의율** 2026-09-03 검색 기준, 2026-02-06 디벨로퍼뉴스 보도(45%) 이후 공개 갱신 없음. 7개월 무소식 자체를 신호로 볼 것 (Q2 유지)

- **세대수** 약 1,800세대(미확정). 민간 정리자료는 1,823세대·최고 40층·2033-10 입주 목표로 유통되나 서울시 확정 고시치 아님 (D)

- **상방 요인** 상도14·15·16·23·24·25 여섯 구역 신통기획 동시 추진
  - 상도15: 141,286㎡·3,204세대·공사비 1조4,367억·대우건설 선정, 사업시행인가 대기 (최선두)
  - 상도14: 상도동 244 일대·최고29층·1,191세대, 2025-04 정비구역 지정·2025-10 사업시행자 지정

  - 상도15 사업시행인가 고시문이 나오면 16구역 사업성 추정 정확도가 크게 올라감
  - 여의도·강남 배후 주거지, 서부선 신상도역 기대감. 흑석뉴타운(동)과 노량진뉴타운(서) 사이 입지
- **벤치마크 — 상도15 정비계획(안)** (2024-09-26 하우징워치, C)
  - 추정비례율 101.41% = (총수입 2조5,767억 − 총지출 1조5,443억) / 종전자산 1조179억

- **최대 리스크 — 진도** 정비구역 지정 전 단계. '연내 구역지정'은 추진준비위원장 목표 발언이며 확정 일정 아님

- **규제** 신통기획 후보지는 선정과 동시에 토허구역 지정 + 권리산정기준일 고시 + 건축허가 제한. 2025-08-27 선정이므로 기준일은 2025년 소급 가능성 높음 — 고시일자 확인 필수
- **비교단지** e편한세상상도노빌리티(2018-12 입주, 893세대, 동작구 만양로 6, 전용 84.63~140.23㎡)
  - 2026-07-01 전용84.97㎡ 17층 22.70억 — 국토부 매매 실거래 원본 확인 (KB C → **A 승격**). 단 2026년 8건 중 **최고가**다
  - KB 34평 시세 21.75억(2026-07-17, 상위 22.6억/하위 20.5억), 매물평균가 24.1억
  - 직전 실거래 2025-12-18 전용84.97㎡ 21.20억(국토부) 확인
  - 2026년 전량(중개거래 8건): 21.30(01-30)·22.60(04-01)·21.10(04-18)·20.75(04-25)·21.00(05-22)·21.48(05-26)·22.00(05-28)·22.70(07-01) → **중앙값 21.39억, 평균 21.62억**. 상승 추세라기보다 21억대 횡보다
  - **입지 할인 필요**: 노빌리티는 상도역 인근 평지, 상도16은 국사봉 고지대. 추정 블록 B안(16.04~17.11억) 사용 권장
- **구역 내 실거래 (v1.5 신설)** 상도동 214번지 일대 2026년 연립다세대 유효 20건 — 범위 1.80~6.20억, 중앙값 4.60억, 평균 4.24억. 대지권 27㎡ 이상 9건 중앙값 5.70억(2.80~6.20). 반지하(−1층) 3건 1.80/2.50/3.15억. 국토부 원본 (A)
