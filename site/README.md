# site/ — GitHub Pages 빌드

`site/build.mjs`가 마크다운 원본을 읽어 `_site/`를 만든다. CI(`.github/workflows/pages.yml`)에서만 실행되고 산출물은 커밋하지 않는다.
**데이터 세션에서는 이 디렉터리를 열지 않는다.** 페이지는 파생물이다.

로컬 확인: `node site/build.mjs` 후 `_site/index.html`을 연다. 서버 불필요.

## 파서가 기대는 md 규약

이 다섯 가지만 지키면 새 구역은 md 추가만으로 카드·페이지가 생긴다. 깨지면 빌드가 실패한다(CI 빨간 X).

1. **요약표** — `10_REGION_REGISTRY.md`의 `## 요약표` 아래 첫 표. 열 15개: `#` 구역 사업방식 단계 초기필요자금 실거주매매가 조합원분양가 권리가액 추가분담금 최종투자금액 비교시세(원안) 비교시세(검증) 안전마진(검증) 토허(내국인 빌라) 신뢰도. `—`는 미확보, `추정블록 참조`·`미확보`는 문자열 그대로 인식.
2. **구역 파일** — `regions/NN_slug.md`. 첫 줄 `# N. 구역명 (방식)`. N은 요약표 번호와 일치해야 하고 URL이 된다. slug는 ASCII, 파서는 읽지 않는다.
3. **속성 불릿** — `- **라벨** 값`. 인식 라벨: 위치 · 사업방식 · 단계 · 면적 · 세대수 · 권리산정기준일 · 비교단지(또는 비교시세) · 구역 내 실거래 · 리스크 · 최대 리스크. 라벨 뒤 꼬리(`(v1.8)`, `— 확보 불가`)는 무시하되 `최대 리스크 — 한 줄`의 한 줄은 카드 문구로 쓴다. 위치 불릿에 `○○구` 또는 `○○시`가 있어야 자치구가 잡힌다. 비교단지 불릿(하위 불릿 포함)의 `종합 X` 또는 첫 `(X)`가 비교시세 등급이 된다.
4. **추정 절** — 구역 파일의 `## 추정 (요약표 병합 금지)` 아래 첫 표. 열에 `시나리오`가 있으면 낙관·중앙·비관(안전마진 열의 최소~최대가 레인지), `항목 | 값 | 등급 | 근거`면 항목 카드. 초기자금은 `초기필요자금 **X~Y억**` 또는 항목 표의 `초기필요자금`/`갭` 행에서 읽는다.
5. **OPEN QUESTIONS** — `| # | 구역 | 확인할 것 | 확인처 | 상태 |`. 구역 셀에 구역명 일부가 들어가면 그 구역에 붙는다(`상도16·갈현510-1`처럼 `·`로 나열하면 둘 다). 상태 셀이 `해소`로 시작하면 해결, `부분해소`·`미해결`은 미해결.
6. **매물 절 (선택)** — 구역 파일의 `## 매물 …` 아래 첫 표. 필수 열 `물건` `점수` `링크`, 선택 열 `순위` `호가` `유형` `면적` `층`. 링크 셀은 마크다운 링크를 `·`로 나열한다(`[재개발닷컴](url) · [네이버](url)`). 헤딩 다음 첫 문단이 노트다 — 첫 링크가 출처, 첫 `YYYY-MM-DD`가 수집일로 페이지 소제목에 찍힌다. 페이지는 상위 3행(물건·점수·링크)만 보이고 전체 표는 "매물 전체" 접힘에 들어간다. 절이 없으면 아무것도 표시하지 않고, 절만 있고 표가 없으면 "0건"과 노트만 보인다(수집했는데 매물이 없는 구역). 링크 라벨에 `모바일`이 들어간 링크(`[네이버 모바일](m.land…)`)는 따로 그리지 않고 `네이버` 링크의 `data-m`으로 붙어, 모바일 UA에서 그 주소로 바뀐다 — PC용 `new.land.naver.com/houses?ms=…`는 모바일에서 루트로 튕기기 때문이다. 모바일 주소는 네이버페이 부동산 형식 `fin.land.naver.com/map?center=<b62(lng)>-<b62(lat)>&zoom=17&…`이며 인코딩 규칙은 DECISIONS #19에 있다(m.land 레거시 `/map/…` 경로는 좌표를 버리므로 쓰지 않는다). 절이 `## 추정`보다 뒤에 와야 추정 접힘에 섞이지 않는다(파서는 `## ` 경계로 자른다).

### 단계 → 단계 맵 행

요약표 `단계` 셀의 키워드로 정한다. 사업방식에 `모아`가 있으면 모아타운 규칙.

| 키워드 | 행 |
| :-- | :-- |
| 착공 | 7 입주 |
| 관리처분 | 6 착공 |
| 사업시행인가 + 진행·준비·목표 / 사업시행인가 | 4 / 5 |
| 통합심의 (모아타운 / 재개발·신통) | 2 / 4 |
| 관리계획…고시, 정비구역 지정 | 3 조합설립 |
| 조합설립 + 징구·동의·준비·추진 / 조합설립인가 | 3 / 4 |
| 후보지 선정, 대상지 선정 | 2 구역지정 |
| 추진위, 접수, 신청 | 0 신청 |

안 맞으면 카드가 "단계 미분류" 행에 놓이고 빌드 로그에 경고가 남는다. 조용히 틀리지 않는다.

## 규제 알약

`00_PROJECT_BRIEF.md` §4 표의 행 이름(투기과열지구 · 토지거래허가구역 · LTV · 주담대 절대한도 · 조합원 지위양도)으로 찾고, 숫자만 뽑아 12자 이내로 줄인다. 행이 없으면 알약이 빠지고 경고가 남는다. 토허 알약의 "N곳"은 요약표 토허 열의 `대상` 수.
